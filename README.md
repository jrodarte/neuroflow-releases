# NeuroFlow downloads

Builds of **NeuroFlow**, a dual n-back and working-memory trainer.

**[Download the latest version](https://github.com/jrodarte/neuroflow-releases/releases/latest)**

| System | File |
|---|---|
| Windows 10 / 11 | `NeuroFlow_<version>_windows.zip`. Extract it, then run `NeuroFlow.exe` |
| Linux (x86_64) | `NeuroFlow_<version>_linux.tar.gz`. Extract it, then run `./NeuroFlow` |

Once installed, NeuroFlow checks for updates when it starts. Click **Update now**
and it installs the new version and keeps your progress.

`SHA256SUMS.txt` in each release lists the checksums the in-game updater verifies.

This repository holds release builds only.
